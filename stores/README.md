# stores/ — Zustand

Локальный UI-стейт (`CLAUDE.md` §5):

- `theme` (`'light' | 'dark'`) — персистентный через AsyncStorage, свитч на
  экране Settings.
- premium-флаг на этапе моков.
- состояние форм «в моменте», тумблеры, состояние таймера модуля,
  черновик сообщения в чате и т.п.

«Серверный» стейт сюда не кладём — он в `hooks/api/` (TanStack Query).
