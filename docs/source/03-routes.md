# Route Registry (§5)

Формат по каждому route: `ID | Path | Auth | Premium | Nav type | Entry points | Destinations | Back`.
Полная спецификация экрана (Layout/Components/States/Animations и т.д. — §52)
создаётся отдельно **на этапе Implementation**, после подтверждения этого
реестра — здесь только реестр, не полная спека.

## Deep linking (черновик, `IMPORTANT`)

Предлагаю поддержать deep link минимум для: `RESULTS`, `UNIVERSITY_DETAILS`,
`PAYWALL` (маркетинговые кампании), `AI_CHAT`. Остальные — по мере
необходимости. Схема: `unipath://<path>` + Universal Links/App Links на
будущий домен продукта — точный домен неизвестен, зафиксировать в
`app.config.ts` при бутстрапе.
